# triplog

"TripDiary(여행일기)" 앱의 개인정보처리방침 공개 페이지입니다. 영어·한국어 두 언어를 한 페이지에서 전환합니다.

GitHub Pages로 호스팅되며, 이 저장소는 정책 페이지 공개 용도로만 사용됩니다.

공개 URL
- 영어(기본): https://codebrunch.github.io/triplog/
- 한국어: https://codebrunch.github.io/triplog/?lang=ko

한국어 기기에서 열면 한국어로 시작하고, 그 외에는 영어로 시작합니다.
플레이 콘솔에는 기본 URL 하나만 등록하면 됩니다.
